## Contribution policy
- Each member commits **their own work**, under **their own GitHub account**, with real dates.
- Work stays within your own module folder; open a pull request to `main` for shared changes.
- No co-author trailers are appended to commits — authorship is the committing member alone.
- Never commit secrets. This repository is public; tenant keys belong in `server-edge/config.php`
  (git-ignored).

See `CONTRIBUTING.md` for the workflow and `SETUP_FOR_TEAMMATES.md` for first-time setup.
