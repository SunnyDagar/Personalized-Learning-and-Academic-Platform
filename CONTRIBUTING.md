# Contributing

1. Create your **own** GitHub account (if you don't have one) and ask Sunny to add you as a collaborator.
2. Authenticate on your machine — either:
   - GitHub CLI: `gh auth login` → GitHub.com · HTTPS · browser, **or**
   - a Personal Access Token you create in your own account (Settings → Developer settings → PAT).
3. Set your identity so commits are attributed to *you*:
   ```bash
   git config user.name  "Your Name"
   git config user.email "your.github@email"
   ```
4. Work only inside **your** `modules/<you>/` folder. Commit real work with real dates. Open a PR to `main`.

We do **not** backdate commits or commit under each other's names — the timeline must be genuine.
